# PySpark Data Engineering Project

## Overview
This project demonstrates a simple end-to-end ETL pipeline using PySpark.
It includes:
- Data ingestion
- Data cleaning
- Transformation
- Aggregation
- Star schema modeling

## Tech Stack
- PySpark
- Python
- Data Modeling (Star Schema)

## Project Flow
1. Read raw sales data
2. Clean invalid records
3. Calculate total sales
4. Aggregate customer-level metrics
5. Build fact and dimension tables
